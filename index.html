Set

A set is a well-defined collection of distinct objects called elements.

A = {1, 2, 3, 4}

1, 2, 3, and 4 are elements of A.

3 ∈ A   7 ∉ A

Set-Builder Notation

Describe a set by stating the property that every element satisfies.

A = { x | x is a positive integer less than 5 }

Therefore:
A = {1, 2, 3, 4}

Read the vertical bar as “such that.”

Reasoning: Deductive & Inductive

🧠 Deductive Reasoning

Starts with general rules or premises and leads to a specific conclusion. If the premises are true and the logic is valid, the conclusion follows necessarily.

1. All triangles have three angles.
2. This shape is a triangle.
3. Therefore, this shape has three angles.
GENERAL → SPECIFIC

💡 Inductive Reasoning

Starts with specific observations and develops a general conclusion. The conclusion is probable rather than guaranteed.

1. 2 is prime.
2. 3 is prime.
3. 5 is prime.
4. Therefore, odd numbers greater than 1 may be prime — but not always.
SPECIFIC → GENERAL
